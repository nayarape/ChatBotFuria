# 🐾 FURIA Fan Chat

Bem-vindo ao **FURIA Fan Chat** — um chat interativo para torcedores da equipe FURIA acompanharem partidas ao vivo, conversarem entre si e receberem atualizações automáticas durante o jogo!

## 🚀 Sobre o Projeto

Este projeto é uma aplicação web simples que simula um ambiente de chat entre torcedores da FURIA. O sistema inclui:
- Bot que responde perguntas frequentes (ex: horário do jogo, escalação)
- Atualização ao vivo do status da partida e do placar
- GIFs automáticos para comemorações
- Mensagens de outros torcedores simuladas para criar imersão

## 💻 Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- API de GIFs da **GIPHY**

## 🎯 Funcionalidades

- 👥 Escolha seu apelido para participar do chat
- 🤖 Pergunte sobre horários, escalação e próximo jogo
- 🏆 Receba GIFs e mensagens especiais ao mencionar "gol" ou "ponto"
- 🔄 Atualizações automáticas de adversário, mapa e status da partida
- 📈 Botão para simular atualização de placar

## ⚡ Palavras-Chave Que o Bot Reconhece

| Palavra digitada         | Resposta automática               |
| ------------------------ | --------------------------------- |
| `gol`, `ponto`           | Mensagem de comemoração + GIF     |
| `horário`, `quando`      | Informa o horário do próximo jogo |
| `escalação`, `jogadores` | Mostra os jogadores da FURIA      |
| `próximo`, `jogo`        | Informa adversário e mapa         |
